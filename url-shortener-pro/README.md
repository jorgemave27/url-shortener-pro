# 🔗 URL Shortener PRO

Acortador de URLs tipo Bitly construido con FastAPI, PostgreSQL y Redis.

## 🚀 Features

- Crear URLs cortas
- Redirección automática
- Conteo de clicks
- Cache con Redis
- Arquitectura por capas (service layer)

## 🧱 Stack

- FastAPI
- PostgreSQL
- Redis
- SQLAlchemy
- Docker
